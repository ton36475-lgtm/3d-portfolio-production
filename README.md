# SIRAWAT × BALL — 3D atelier

Bilingual (EN/TH) creative portfolio. Orbit a dark room, click a frame, open the case study.

**GitHub (Grok + Codex share this):** [ton36475-lgtm/3d-portfolio-production](https://github.com/ton36475-lgtm/3d-portfolio-production)

## Run

```bash
npm install
npm run dev
```

Preview listens on port 8080.

## Stack

- TanStack Start + React 19 + Tailwind v4
- Three.js · React Three Fiber · drei
- No auth, no database
